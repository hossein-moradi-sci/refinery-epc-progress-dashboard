# راهنمای همگام‌سازی داشبورد با MS Project

## معماری

```
┌─────────────────────────────┐
│  MS Project                 │
│  Project-File\*.mpp         │
│  (فیلد Physical % Complete) │
└──────────────┬──────────────┘
               │  export-msp-data.ps1
               │  (دستی — با Sync-Now.vbs، دکمهٔ Sync صفحه، یا فایل اجرایی پاور بی آی)
               ▼
┌─────────────────────────────┐
│  data\tasks.csv             │
│  data\project-info.csv      │
└──────────────┬──────────────┘
               │  خواندن با دکمه Refresh در Power BI
               ▼
┌─────────────────────────────┐
│  Power BI Desktop           │
│  Refinery8-FGR.pbip         │
│  داشبورد پیشرفت آیتمیک      │
└─────────────────────────────┘
```

## گام اول — همگام‌سازی دستی (هیچ چیز خودکار نیست)

روی این سیستم هیچ Task زمان‌بندی‌شده‌ای نصب نیست و لازم هم نیست — چیزی هر ۱۵ دقیقه روی صفحه ظاهر نمی‌شود.

1. روی میانبر **Sync Dashboard Data** روی دسکتاپ دوبار کلیک کنید (فایل `Sync-Now.vbs`).
   اسکریپت بدون هیچ پنجره خط فرمانی اجرا می‌شود و چند ثانیه بعد پیام «Data synced» را نشان می‌دهد.
2. بعد در Power BI Desktop دکمه **Refresh** را بزنید.

> مهم: دکمه Refresh به‌تنهایی داده را از MS Project نمی‌خواند؛ مدل Power BI فقط CSV روی دیسک را می‌خواند.
> پس ترتیب همیشه این است: **اول Sync، بعد Refresh**.

اجرای دستی در PowerShell (این یکی پنجره خط فرمان باز می‌کند): `.\export-msp-data.ps1`

## گام دوم — دکمه اختیاری داخل Power BI

اگر می‌خواهید همین Sync داخل خود Power BI یک دکمه باشد، فایل `Register-CustomPart.ps1` را
با دسترسی ادمین اجرا کنید تا دکمه **Sync with MS Project** در تب External Tools اضافه شود
(نیاز به ری‌استارت Power BI). این دکمه فعلاً نصب نیست و اختیاری است؛ میانبر دسکتاپ کافی است.

## فیلدهای کلیدی مدل

| ستون در Power BI | منبع در MS Project |
|------------------|-------------------|
| WeightPercent | Number1 (وزن آیتمیک) |
| PlannedWeight | Number1 × PercentComplete |
| ActualWeight | Number1 × Physical % Complete |
| PercentComplete | % Complete |
| PhysicalPercentComplete | Physical % Complete |

محاسبات DAX:

- **پیشرفت واقعی آیتمیک** = Σ(ActualWeight) ÷ Σ(WeightPercent)
- **پیشرفت برنامه‌ای آیتمیک** = Σ(PlannedWeight) ÷ Σ(WeightPercent)
- **انحراف** = واقعی − برنامه‌ای

این دقیقاً همان منطق فایل MSP است؛ بعد از هر Sync اعداد داشبورد همان چیزی را نشان می‌دهند
که خود MSP روی خلاصه‌ها محاسبه می‌کند.

## فایل MPP — پوشهٔ `Project-File`

هیچ مسیر ثابتی در این اسکریپت نیست. فایل MPP خودکار پیدا می‌شود، به این ترتیب:

1. `<داشبورد>\Project-File`  ← پوشهٔ پیشنهادی؛ فایل جدید را همین‌جا بگذارید
2. `<پوشهٔ بالای داشبورد>\Project-File`  ← در چیدمان پرتابل
3. `<داشبورد>`  ← اگر فایل را کنار خود `Refinery8-FGR.pbip` گذاشتید
4. `<پوشهٔ بالای داشبورد>`

اگر چند فایل `.mpp` در این پوشه‌ها باشد، **جدیدترین** (بر اساس تاریخ تغییر فایل) انتخاب می‌شود؛
پس جایگزین کردن فایل قبلی با فایل جدید همیشه اثر می‌کند و لازم نیست نام فایل را عوض کنید.
برای انتخاب دستی یک فایل خاص: `-MppPath "D:\path\to\file.mpp"`.

مسیرهای `data` و `logs` هم نسبت به محل همین اسکریپت حساب می‌شوند، پس کل پوشه را می‌توان به هر
درایو یا سیستم دیگری کپی کرد و هیچ چیزی نیاز به ویرایش ندارد.

> نکته: مدل Power BI مستقیماً از `data\tasks.csv` و `data\project-info.csv`
> خوانده می‌شود — همان فایل‌هایی که این اسکریپت می‌نویسد.
